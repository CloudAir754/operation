# 实施状态

本文档用于把 README 的设计要求映射到可验证实现，避免将部分原型误报为全部完成。

## 阶段 1：只读本地原型

- [x] 本地启动、随机端口、浏览器打开、SQLite 初始化、回环限制和启动会话令牌。
- [x] 系统能力、CPU、内存、挂载点、inode、磁盘 I/O、网络和块设备稳定身份。
- [x] 本机账号、逻辑/物理 home、文件系统关系和 sudoers 来源的只读展示。
- [x] NVIDIA 多 GPU 总览和计算/图形进程；不支持指标逐字段为 `N/A`。
- [x] 可取消的 home 后台扫描、SSE 进度、硬链接去重和 ECharts treemap。
- [x] 按用户名或 UID 在选定挂载点内限速扫描，展示逻辑/实际占用、文件数、最大路径、进度和权限盲区。
- [x] treemap 下钻、大小排序、所有者/大文件筛选、异常标记、摘要导出，以及带有效期的 SQLite 快照和启动清理。
- [ ] 在实际 RTX 3090 及更新硬件上完成 NVML 兼容性验证；当前开发机无 NVIDIA GPU。

## 阶段 2：账号与登录管理

- [x] CSV、XLSX、文本三种用户导入解析与逐行预览。
- [x] 随机密码规则校验、脱敏预览和密码学安全生成器。
- [x] 实际 PAM 策略读取、安全修改与恢复。
- [x] 幂等的单个/批量用户创建和仅启动用户可读的一次性凭据导出。
- [x] SSH 公钥校验、指纹去重、原子写入、所有权、mode 和 ACL 验证。
- [x] sudo 独立规则文件新增、`visudo` 前后校验和仅撤销本程序规则。
- [x] TCP/UDP 端口占用查询、稳定进程身份核验、单进程及按 UID 全进程受控终止。
- [x] 删除用户预检、登录禁用、UID 进程终止、二次确认和 home 安全边界。

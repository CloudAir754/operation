## 2026-08-27：SSH 公钥与托管 sudo 规则

- SSH 公钥仅接受 RSA、ECDSA、Ed25519 和 OpenSSH 安全密钥格式，校验二进制 blob 声明类型并按 SHA256 指纹去重；预览和任务数据库不保存 base64 密钥材料。
- 写入前验证 home、`.ssh` 和 `authorized_keys` 的类型、所有者、符号链接边界及 ACL，使用目录文件描述符和 `O_NOFOLLOW` 限定路径，临时文件原子替换后再次强制 `0700`/`0600`。
- sudo 授权只写 `/etc/sudoers.d/labopspanel-uid-<uid>`，写入前验证全局配置，替换前验证临时规则，替换后再次验证全局配置，失败时恢复旧内容。
- sudo 撤销只接受带本程序标记且内容与用户名、UID 完全匹配的规则；不会移除 sudo 组成员关系或改写管理员手工规则。
- SSH 和 sudo 操作使用串行持久化任务、幂等键和固定特权动作；API、工作线程与 root 助手均携带或复核稳定 UID，阻止执行期间用户名被重新绑定。
- 前端账号表增加 SSH 公钥粘贴、sudo 授予和托管规则撤销入口，只有可信助手可用时才启用，并展示逐步执行结果。
- 测试使用临时 home、sudoers 目录和特权执行替身，覆盖重复密钥、符号链接、异常 ACL、已有规则、`visudo` 失败回滚、非托管规则拒绝及 UID 传递；未写入开发机真实 home 或 sudoers。

- 独立 sudoers 文件按启动用户 UID 命名，只精确允许四个固定动作，不允许额外参数、通配符或 shell；已有非安装器规则一律拒绝覆盖。
- 安装前验证全局 sudoers，写入前验证权限为 `0440` 的临时规则，替换后再次验证全局配置；末次验证失败时恢复原规则并再次校验。
- 提供 `--dry-run` 计划预览；自动化测试只验证纯规则生成，未在开发机执行 root 安装或改写真实 sudoers。

- 修改范围限定为 `pwquality.conf` 的已知字段；最小长度不低于 15，只允许非正 credit，并限制类别、重复、连续、用户名检查、重试和历史差异参数的类型与范围。
- 完整保留注释和未修改字段；未知键、异常行、重复定义、非 UTF-8、符号链接、不安全所有者或权限均阻断写入，不覆盖无法理解的手工配置。
- 修改预览展示当前实际值、目标有效值和模块行参数冲突；`pam_pwquality` 缺失、PAM 堆栈未启用或模块参数会覆盖目标字段时保持只读。
- 管理员必须输入固定确认文本才能启动修改；任务参数只保存策略值，不保存确认输入，并由 root 助手再次执行全部能力和路径检查。
- 每次修改先在 `/var/lib/labopspanel/pam-backups` 保存权限为 `0600` 的原文件与哈希清单，再原子替换主配置并重新读取实际 PAM 策略；不生效或能力异常时自动恢复并清理失败备份。
- 人工恢复绑定具体备份 ID，同时校验备份哈希和当前配置必须仍等于该次应用结果；检测到后续人工修改时拒绝覆盖，恢复后实际策略不匹配则重新应用恢复前配置。
- 特权安装白名单扩展为六个精确动作，新增 `pam-update` 和 `pam-restore`，没有开放任意文件路径或 shell 参数。
- 测试覆盖正常修改/恢复、未知与重复配置、模块优先级冲突、写后验证失败回滚、后续人工修改拒绝、确认文本和持久化幂等；未修改开发机真实 PAM 配置。

## 2026-08-28：端口占用与进程控制

- 增加 TCP/UDP 本地端口查询，展示地址、状态、PID、UID、用户名、进程启动时间和命令；可信助手提供完整 root 只读视图，助手缺失时普通权限结果明确标记可能不完整。
- 单进程终止同时绑定 PID、实际 UID 和启动时间，API 提交时预检，root 助手发送信号前再次核验，避免进程退出后 PID 被复用导致误杀。
- 进程默认先接收 `TERM` 并等待 5 秒，只对身份仍完全一致的存活进程升级 `KILL`，最后验证进程已经消失。
- 按用户终止以 `/etc/login.defs` 的 `UID_MIN` 区分普通账号，按稳定 UID 扫描所有进程，重复处理短暂重生进程并要求最终无残留。
- root、系统账号、启动 LabOpsPanel 的用户、PID 1，以及经调用祖先链验证的面板进程树均不可作为批量或受保护终止目标。
- 两类终止均要求输入绑定 PID 或用户名的确认文本，通过单线程持久化任务和幂等键执行；SQLite 与操作日志只保存身份及结果摘要，不保存进程命令行。
- 特权安装白名单扩展为九个精确动作，新增 root 端口只读查询、单进程终止和按 UID 终止，不接受任意信号、命令或 shell。
- 自动化测试使用当前测试进程监听的临时端口和专门创建的休眠子进程，覆盖查询、正常 TERM、PID 身份变化、面板树保护、按 UID 重扫和 API 确认；未终止开发机既有进程。

## 2026-08-28：用户删除安全流程

- 删除前以本机 passwd 的用户名、稳定 UID 和逻辑 home 绑定十分钟有效预检，展示进程、会话、持有 home 文件的 PID、用户计划任务、sudo 来源、物理 home 和同文件系统磁盘占用。
- 账号删除与 home 删除分别判断阻断条件；共享、符号链接、异常所有权或权限、嵌套挂载和检查不完整只关闭递归 home 删除，不会把危险路径交给 `userdel -r`。
- 执行时先锁定密码并切换到 `nologin`，再按 UID 终止全部进程并重新采集系统事实；账号、home 的设备号或 inode 变化，以及残留进程或被占用文件都会中止操作。
- 非本程序托管或读取不完整的 sudoers 规则、系统 cron 引用会阻断账号删除；本程序托管规则只通过原有校验接口撤销，用户 crontab 和目标 UID 的 at 作业在账号删除后清理。
- 删除 home 前要求父目录由 root 所有且不可由其他用户写入，通过目录文件描述符复核 inode，并在同一父目录 rename 到随机隔离名；账号删除失败会恢复 home、托管 sudo 和原登录状态，账号成功后才使用抗符号链接攻击的递归清理。
- 前端提供“删除预检”“仅删除账号并保留 home”“删除账号及 home”三段入口，不可逆动作必须完整输入用户名；成功后自动刷新本机账号列表。
- 特权安装白名单扩展为十一个精确动作，新增用户删除预检和删除；自动化测试只使用临时 passwd/home、命令替身和持久化任务替身，未删除开发机真实账号或文件。

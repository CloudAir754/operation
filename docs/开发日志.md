# 开发日志

## 2026-08-27：项目规划

- 创建 LabOpsPanel 仓库并完成首版需求分析。
- 确定“中心控制端 + 受限主机 Agent”的建议架构。
- 将用户目录迁移和新硬盘初始化定义为带预检、校验、审计及回滚的高风险状态机任务。
- 当前仅包含文档和开发规范，尚未开始编码。

## 2026-08-27：收敛为本机按需运行

- 根据使用场景移除中心控制端、远程 Agent、多机管理、复杂角色和审批设计。
- 数据库固定使用 SQLite，程序仅监听本机回环地址并按需启动。
- 批量用户输入增加 XLSX 和空白字符分列的文本粘贴方式。
- 增加随机密码生成规则与 Ubuntu PAM 密码策略的读取、修改、验证和恢复设计。
- 增加 SSH 公钥格式校验、指纹去重、原子写入及所有者和权限校验设计。

## 2026-08-27：明确系统、GPU 与迁移需求

- 兼容性范围明确为 Ubuntu 22.04、24.04 和 26.04 LTS，账号默认按普通本机账号处理。
- NVIDIA GPU 页面调整为 nvtop 风格，展示进程所在 GPU、显存和可获取的进程利用率，并明确整卡带宽不能伪装成进程带宽。
- 文本用户导入确认中文名不含空格，初始密码必须导出。
- 未知文件系统先做能力识别，未验证的网络、加密或特殊文件系统不开放迁移。
- 用户 home 迁移改为终止 UID 全部进程、检查空间、原地 rename、rsync、校验、建链接、人工试验和独立确认清理的顺序。
